🚀 Quick Setup Guide

1

Load Extension into Browser (Zero Downloads)

Go to chrome://extensions (or edge://extensions) → enable Developer mode → click Load unpacked → choose the extension folder.

2

Add Browser Source in OBS Studio

In OBS, click + under Sources → Browser → Check Local file → select overlay.html → set Width 500, Height 300.

3

Play YouTube or YouTube Music!

Play any video or playlist. The overlay updates automatically in real-time!
