🚀 Quick Setup Guide

1

Load Extension into Browser (Zero Downloads)

Go to chrome://extensions (or edge://extensions) → enable Developer mode (top right toggle) → click Load unpacked → choose the extension folder from this project.

2

Add Browser Source in OBS Studio

In OBS Studio, click + under Sources → Browser → check Local file → select overlay.html (or paste the copied OBS File Link) → set Width 500, Height 300.

3

Play YouTube or YouTube Music!

Open YouTube Music or YouTube in any tab and press play. The live song detector above will turn green, and your OBS overlay updates in real-time!
