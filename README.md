# yt-music-obs-overlay
simple vibecoded overlay for yt music
simply because i want something that just works without having to do this and that

## How to Use

### 1. Load the Browser Extension (Zero external downloads)
1. In your browser (Chrome / Brave / Edge / Opera), go to `chrome://extensions` (or `edge://extensions`).
2. Toggle on **Developer mode** in the top-right corner.
3. Click **Load unpacked** (top-left) and select the `extension` folder from this repository.

---

### 2. Add to OBS Studio
1. In OBS Studio, click **`+`** under **Sources** $\rightarrow$ select **Browser**.
2. Set the URL to your local overlay file or the GitHub Pages URL:
   ```text
   https://afterlight0338.github.io/yt-music-obs-overlay/
   ```
   *(or use local file: `file:///path/to/yt-music-obs-overlay/overlay.html`)*
3. Set **Width**: `500`, **Height**: `250`.
4. Click **OK**.

---

### 3. Play & Customize Live!
1. Open **YouTube** (`youtube.com`) or **YouTube Music** (`music.youtube.com`) and play any song/video.
2. Click the extension icon in your browser toolbar to change themes (**Modern Glass**, **Compact Pill**, **Spinning Vinyl**, **Cyberpunk HUD**, **Spotify Bar**, **Lo-Fi Anime**, **Retro 8-Bit Pixel**, **Ultra Minimal**) or accent colors.
3. **Themes change dynamically in real-time in OBS** — you never need to edit your OBS browser source link!
